## ✨ Recursos Incríveis
- **Operações Básicas:** Adição, Subtração, Multiplicação e Divisão
- **Design Moderno:** Interface escura com efeitos de profundidade
- **Responsividade:** Funciona perfeitamente em todos os dispositivos
- **Histórico Visual:** Display grande para melhor visualização
- **Funções Especiais:**
  - Botão Clear (`C`) para limpar instantaneamente
  - Suporte a números decimais
  - Efeitos visuais nos botões
  - Cálculos em cadeia (ex: `3+5*2`)

## 🚀 Como Usar
1. Clone o repositório:
```bash
git clone https://github.com/seu-usuario/calculadora.git
```
2. Abra o arquivo `index.html` no seu navegador preferido

**Operação Rápida:**
```js
5 + 3 × 2 = 11  // Experimente no display da calculadora!
```
